# Java Linked List Management System

A menu-driven Java application to perform basic operations on **Singly Linked Lists** and **Doubly Linked Lists**. This project demonstrates linked list implementation, node management, and fundamental data structure operations.

## Features

- Singly Linked List implementation
- Doubly Linked List implementation
- Menu-driven interface
- Insert and manage nodes
- Perform linked list operations through the console

## Technologies Used

- **Language:** Java
- **Concepts:** Data Structures, Linked Lists, Object-Oriented Programming

## Project Structure

```text
Java-Linked-List-Management-System/
├── Main.java
├── SinglyLinkedList.java
└── DoublyLinkedList.java
```

## Prerequisites

- Java Development Kit (JDK 21 or compatible version)
- Terminal or command prompt

## How to Run

Compile the Java files:

```bash
javac Main.java SinglyLinkedList.java DoublyLinkedList.java
```

Run the application:

```bash
java Main
```

## Learning Objectives

- Understand singly and doubly linked lists.
- Practice node creation and pointer/reference manipulation.
- Apply data structure concepts using Java.
- Develop a menu-driven console application.
